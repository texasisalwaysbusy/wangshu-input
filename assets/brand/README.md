# Wangshu Input artwork / 望舒输入法图片

Project-native SVG artwork in moon white `#F7F5EF`, deep indigo `#242B49` and moon gold `#B99751`.

- `logo.svg`: 512 × 512 crescent-and-keyboard mark.
- `logo-inset.svg`: 512 × 512 with transparent outer padding.
- `banner.zh-CN.svg`, `banner.en.svg`: 1600 × 640 README banners.
- `features.zh-CN.svg`, `features.en.svg`: 1600 × 1080 feature diagrams.
- `social-preview.svg`: 1280 × 640 repository sharing composition; convert to PNG if a platform requires raster uploads.
