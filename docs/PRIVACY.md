# Android 数据处理说明（开发预览）

2026-11-03：根据本仓库 Android 源码补充可选学习、剪贴板历史和手动导出的说明。本文是源码行为说明，不是已完成的设备隐私审计，也不描述 Windows 版本。实际安装包、系统服务及依赖仍需分别核验。不要在未完成验收的预览中输入密码、身份资料或其他敏感内容。

## 输入与候选个性化

输入法需要通过 Android 的编辑器接口处理当前输入、选区及部分上下文。没有开启自动学习，不代表完全不读取编辑器内容；例如候选确认、光标编辑和联想会使用当前编辑器提供的信息。

“候选个性化”的自动学习默认关闭。开启后，会临时读取编辑器前后快照来核对候选是否插入；能核对成功的路径才排队记录拼音、所选词、选择计数、更新时间及固定状态，用于本机个人排序。记录位于应用私有目录的 `candidate-learning-v1.tsv`；其中词语的 Base64 编码不是加密。该记录不是逐键日志，也不是整段编辑器内容备份，但所选词本身仍可能含敏感信息。

- 关闭或临时暂停自动学习不会删除已有个人排序；手动固定、取消固定、忘记候选是独立操作，关闭自动学习不等于禁止所有手动存储。
- 临时暂停只持续到输入法进程重启。关闭、暂停或输入会话变化会取消尚未开始处理的自动任务；此前已经开始处理的任务仍可能完成保存。
- 当前实现最多保留 256 条拼音与词语组合记录，每个拼音最多前置 24 个。自动权重随时间衰减，衰减不等于按期限删除记录。
- 源码根据编辑器的密码类型和禁止个性化学习标记限制记录。这依赖宿主正确提供标记，不能保证识别所有未标记的敏感内容。

禁止个性化学习标记不是全功能“隐私模式”：上述学习/剪贴板限制不能推及所有语音或手动词库功能。设置页试打区也不承诺“不会保存文本”：编辑器状态可能恢复，启用候选学习后也可能保存所选词。因此本次将试打提示改为要求使用合成文字并说明上述边界；没有修改任何数据行为。

对应实现：[LearningStore](../android/app/src/main/java/org/wangshu/ime/LearningStore.java)、[CandidateLearning](../android/app/src/main/java/org/wangshu/ime/CandidateLearning.java)、[LearningSettingsActivity](../android/app/src/main/java/org/wangshu/ime/LearningSettingsActivity.java)、[WangshuIme](../android/app/src/main/java/org/wangshu/ime/WangshuIme.java)。

## 剪贴板历史

历史记录默认关闭，开启前有单独确认。开启后，源码在键盘显示且当前输入环境允许时监听剪贴板；打开相关面板也可能读取当前剪贴板。当前接收范围为单条纯文本，拒绝 URI、Intent 和系统敏感标记，不读取图片、文件或链接指向的内容。密码及禁止个性化学习的输入环境会阻止该记录路径，但未标记的秘密仍可能被保存。

应用私有目录的 `clipboard-v1.json` 保存文本、条目编号、时间和置顶状态。当前实现没有为这个文件增加应用层加密；“私有目录”不等于内容匿名或在任何环境下都安全。

- 最多 100 条。未置顶内容可选 1、7、30 天，默认 7 天；到期清理是在随后使用历史的相关路径中执行，不是严格的后台定时销毁。
- 置顶项不按上述期限淘汰；满额时仅淘汰未置顶旧项，全部置顶则拒绝新增。
- 关闭记录保留已有历史；删除、取消置顶和“清空全部历史（含置顶）”是单独操作。清空应用历史不会清除系统当前剪贴板，也不会删除已经另存为常用语的副本。
- 不要依赖默认关闭来推断升级后的实际状态，请检查当前设置。历史开关也不是对系统剪贴板或其他应用的数据流控制。

对应实现：[ClipboardStore](../android/app/src/main/java/org/wangshu/ime/ClipboardStore.java)、[ClipboardSettingsActivity](../android/app/src/main/java/org/wangshu/ime/ClipboardSettingsActivity.java)、[WangshuIme](../android/app/src/main/java/org/wangshu/ime/WangshuIme.java)。

## 手动词库、常用语与导出

用户手动添加、修改或导入的词条和常用语保存在应用私有目录的 `personal-v1.json`，与自动学习、剪贴板历史分开。这些手动数据没有自动到期删除规则。把剪贴板内容加入常用语会形成独立副本，不能通过关闭剪贴板记录来撤回它。

“备份词库与常用语”通过系统文件选择器，把该个人数据文件的内容写入用户选定的位置；此导出不包含上述独立的学习文件或剪贴板历史文件，但会包含已从剪贴板转存为常用语的内容。若选择云端文档提供方，该提供方可能接收导出内容；应用没有申请网络权限也不代表这样的用户选择不会把数据交给其他服务。请自行核对目的地，不要把真实备份附在公开问题报告中。

对应实现：[PersonalStore](../android/app/src/main/java/org/wangshu/ime/PersonalStore.java)、[PersonalActivity](../android/app/src/main/java/org/wangshu/ime/PersonalActivity.java)。

## 语音、网络及平台边界

公开 Android manifest 声明录音权限，未声明 `INTERNET`，并设置 `allowBackup="false"`。这不是对所有系统组件、宿主、依赖或设备传输行为的保证，也不是对所有厂商备份/迁移机制的审计结果。

本仓库完整语音路径需要独立依赖和模型，仓库不包含语音模型或定制 AAR，当前界面的“附带语音包”措辞不代表本快照附带它们。源码中的本地录音路径把音频放在内存中送给本地模型，未添加录音历史文件；另有 Android 设备端识别服务调用。设备端识别服务属于系统提供的边界，仍需单独核验。用户主动复制识别结果会写入系统剪贴板，主动插入则会交给当前编辑器。不要把“本地识别”理解为结果不会出现在这些用户选择的目的地。

另一个基础打字变体禁用了语音，但它并非当前公开构建配置，不能用该变体的行为替代本仓库完整版本的隐私或功能验证。区别见[设置页旋转修改与验证边界](SETTINGS-ROTATION-20261103.md)。
