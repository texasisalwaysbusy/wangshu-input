# Beta 状态与已知限制

[返回首页](../../README.md) · [English](BETA-STATUS.en.md)

本说明描述 beta 的能力边界。**某一修复是否进入你下载的文件，只能由该版本发布说明、对应源码与产物哈希确认。** 主机测试、模拟编辑器、Wine、模拟器、真实手机和真实 Windows 是不同层次的证据，不能互相替代。

## Android：可试用，仍有已知问题

完整变体包含本地拼音、显式中英分段、离线语音入口、符号与个人数据工具，但不保证所有宿主兼容。本版已合入以下修复，并用实际生产方法和合成宿主做自动回归：

- 接受 Chromium 式完整文本快照：`partialStartOffset == -1` 表示全文，`partialEndOffset` 不必为 `-1`。首退格和语音 KEEP_TEXT 共用的兼容路径已修正，真正的部分/越界快照仍拒绝。
- 未确认拼音仅保留在键盘内，确认时才向宿主提交。换字段、隐藏与结束输入丢弃本地待确认内容，避免原始拼音变成旧字段正文；不在失焦后补删宿主文字。
- 录音取消时同步复位麦克风选中标志和背景，保留取消后迟到结果不得写入的保护。
- 对取消、换字段、最后一次快照读取，以及迟到选区回调补充身份与读回核对。快照不可用时仍可保守丢弃待确认内容；不盲目重试已发出的写入。

**修复后没有新增人工或真机复验。** 上次 Chrome 报告没有原生快照与身份记录，因此这里只确认代码兼容路径和自动回归，不把它称为真实手机现象的唯一根因，也不保证所有宿主已兼容。图标颜色仍不是录音状态的独立证明。

简拼 `ceshy` 能召回“测试页”，但已有主机查询中排在第 57 位；该排序问题仍保留。

其他尚未闭合的范围：英文与混合语音质量、识别中间结果（partial）、数字与标点格式、长按/滑动语音手势、窄屏触控、横屏遮挡以及不同宿主的提交和选区行为。离线语音样本结果不能外推为通用准确率或手机速度保证。

当前本地例句预测只有 115 条人工编写的固定例句，默认关闭。它不进行开放式生成，不代表通用中英预测、语义理解或语境质量已完成。自动语音纠错学习、快捷翻译、语义润色等也不在本 beta 的已完成能力中。

## Windows：开发实现，真实平台未验收

仓库包含 x86/x64 原生 TSF 代码及检查工具。历史主机或 Wine 记录可以帮助开发，但不能证明当前候选在真实 Windows 上已经可用。

真实 Windows 注册、系统启用、32 位宿主、现代应用、多 DPI、候选位置和真实麦克风仍未完成验收。Windows ARM64 不在当前支持范围。部分剪贴板、符号、预测与设置功能尚未与 Android 对齐；Android 的隐私、持久化及功能测试结论不能直接移植到 Windows。

## 调试签名与数据

Android beta 使用调试签名，不是商店发行签名。跨构建覆盖更新的兼容性尚未建立。请勿用于密码、敏感信息或重要文本；始终保留另一款输入法。

备份不是完整应用快照。个人词库/常用语、设置分别导出；剪贴板历史、录音、模型与学习记录不随这些备份导出。备份请保存在你信任的位置，参见 [隐私说明](PRIVACY.md)。

## 读发布说明时看什么

1. 完整变体还是 **Basic Typing Preview（无语音）**。
2. 精确版本、源码提交/源码包哈希、APK 与可选模型的 SHA-256。
3. 修复来自哪一类验证，哪些仍未运行。
4. 未关闭问题和签名更新限制是否仍适用于该文件。

自愿反馈可以使用合成文本，无需提供私人录音或输入历史。任何测试次数都不应被写成全平台或通用质量保证。
