# 一期开发分支

本分支汇总 Android、Windows 和共享核心的一期开发改动。公开 Beta.2 以其发布页和绑定的源码/产物为准；后续开发分支内容不会自动改变该 APK。

| 范围 | 改动 |
|---|---|
| Android 编辑 | 待确认拼音仅显示在键盘内。会话、选区与写入结果的校验覆盖候选提交、语音和删除。保留 Chromium 系列编辑器的完整文本快照兼容。 |
| Android 语音 | 流式文字显示在独立预览区，松手按最终落点处理。撤销前核对本次插入后的正文和光标。数字格式使用确定性规则。 |
| Android 日常输入 | 横屏键盘留出编辑区；设置与个人数据恢复增加读回和失败回归；拼音、补全和下一词继续使用冻结样本评估。 |
| Windows | 增加剪贴板、符号与表情入口、选区和批量删除、完整字符簇退格，并推进共享候选、个人数据及语音保护。 |
| 共享核心 | 中英文补全与上下文词候选使用有界离线数据，支持数字后续和光标上下文。通用整句预测仍待验收。 |

Windows 开发版可用拼音检索 192 个既有 Emoji 和颜文字条目，精确名称优先，随后为前缀和名称内匹配。查询文字留在候选窗，沿用原字段和组合范围保护。安装与卸载脚本在调用注册工具前先检查两种架构的文件。x64 合成宿主已有检索回归，双架构二进制、实际应用和注册仍待验。

Windows 交付 ZIP 可以在脱离构建机后独立核对。使用交接提供的 SHA-256、随附收据和源码里的核对工具，可比对每个 ZIP 成员、二进制的 PE 架构和解压目录。回退前保留旧版本目录、两种架构的路径和哈希、原默认输入法与兼容备份。 [核对入口](../WINDOWS-RECEIPT-TOOLS.md)

Android 开发版可在「符号」里的「表情」或「颜文字」点「检索」。两端索引来自同一份目录。键入无声调拼音，例如 `weixiao` 或 `maomi`，点结果插入原字形。检索词保留在当前键盘视图中，切框、隐藏和选区变动都会使旧结果失效。此入口待真实设备核对。

两端可在本地个人数据管理中收藏和取消收藏内置表情及颜文字。Android 从对应面板的「收藏」调用，Windows 从双反斜杠符号菜单第三页调用。列表按收藏顺序显示，最多 64 项。主动操作保存收藏，普通插入与检索不会新增记录。包含收藏的 JSON v2 可在两端预览、合并和恢复。兼容旧版的 JSON v1 导出保留词库和常用语。

## 模糊候选入口

启用某组模糊音后，Android 输入拼音并展开候选，点「模糊候选」。Windows 输入拼音后按 Shift+PgDn，按 PgUp 返回首组。该入口最多显示九个结果，保留个人记词优先级，排除首组中已展示的词。普通翻页沿用原顺序。选择模糊候选时，结果不会学到原拼音下。

Windows x64 生产候选路径在合成回放中保持了 2,942 条普通候选记录，独立模糊页覆盖 24 条诊断输入中的 21 条。`suohua` 启用 s/sh 时，「说话」为独立页第一项。Android 本机测试验证了查询上限与候选页动作，手机界面和 Windows 实际应用仍待验。

## Windows 编辑上下文切换

当一个文档切换 TSF 栈顶时，望舒结束上一上下文拥有的组合，在新的编辑字段重新接收拼音。迟到的候选提交和结束组合回调无法接管新字段，后台文档的推入事件不会打断前台组合。旧字段原有内联文字由所在宿主管理，结束操作只请求终止原 TSF 组合。

从首键发起请求到提交结束，编辑归属跟随发起字段。宿主在读取选区附近的内容、建立组合、写入或放置光标时同步切框，旧请求结束后只处理原有组合。已经由宿主写入的文字保留，旧请求不会在新字段继续写入、移动光标或清掉下一组拼音。

原生 x64 合成宿主覆盖正常推入、后台推入、先通知后发布新栈顶、弹出活动上下文及延迟回调五种情况。五项改前均失败，改后均通过。实际 Windows 应用验证为 NOT_RUN，x86 构建为 BLOCKED。

有选区时，Windows 将待确认拼音、混输和候选留在输入法中。按 Esc、退格删完待确认输入或切框时，原选区文字保持原样。确认前核对字段、选区和原文，再替换这一处选区。Windows x64 已用 Emoji、组合重音、同文不同位置选区、过期候选及宿主读回失败验证改动，真实应用仍待验。

## Android 符号、联想和续写撤销

符号按钮、数学结果和续写绑定显示时所在的编辑器。清理语音及撤销状态后再次核对归属，联想写入前还核对完整文字和光标。已显示的旧撤销按钮只对应原来的续写，新一笔续写仍可正常撤销。Chromium 形状的合成回归同时覆盖旧选区通知与新预编辑相遇的情况。主机检查、两变体原生编译和 lint 已通过，实际 Android 宿主仍待验。

批量删除的确认和撤销也各自绑定一次操作。旧手势松手或旧撤销提示不会消耗较新删除的撤销，当前提示仅恢复本次删除的光标前内容。此路径已通过合成编辑器检查，实际 Android 宿主待验。

## 两端个人词库导入

Android 和 Windows 确认导入时使用预览时生成的词库与常用语结果。预览完成后若本机数据发生变化，需要重新预览。Windows 从外部备份修复时也会复核待保留的原文件和备份，确认后保留故障原件的副本。已有 JSON v1 和两列 TSV 的存储及交换方式继续使用。两端合成文件往返和原生 Windows 存储检查通过，实际管理界面和重启恢复仍待验。

Android 的词库与常用语打不开时，可预览本机留存副本，或选择已导出的 JSON v1 备份。页面显示副本来源和条目数，确认后先核对并保留故障原件，再恢复使用。原件留在应用私有目录。正常可读的词库继续通过合并导入补充。合成文件覆盖了取消预览、过期确认、并发保存、故障留存及重新打开。实际文件选择、设备目录同步和重启仍待验。

## 数字面板联想与共用设置

Android 的数字面板和 Windows 的数学模式各有独立联想开关，与普通补全分别保存。Windows 旧设置升级时延续先前在数学模式中的联想选择。关闭联想后仍可在数学模式计算精确结果。

两端共用设置 v2 可交换语音格式、普通补全、光标联想和数字面板联想。导入 v1 时保留本机数字面板联想。完整 Android 备份及 Windows 本机排序保留各自格式。计划回退时，在升级前留存原版本的备份和原安装包。
