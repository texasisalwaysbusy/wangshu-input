# 隐私与数据边界

[返回首页](../../README.md) · [English](PRIVACY.en.md)

此处说明当前 Android 实现的设计与已知限制，不是独立安全审计结论，也不代表 Windows 已通过相同检查。

## 处理在哪里发生

- 当前 Android 清单不声明 `INTERNET` 权限，不要求账户。拼音、候选和规则式数学转换在本地处理。
- 完整变体使用导入的固定离线模型，或尝试系统明确提供的设备端识别接口。模型/服务/权限不可用时不改走云端识别。
- 语音会话的音频在内存中处理，不建立录音历史。退出、切换输入或取消路径有停止保护，但真实麦克风与宿主行为仍有待验证范围。不要只凭图标颜色判断录音已停止。
- Basic Typing Preview 刻意排除语音实现及麦克风权限，不能将它的结果当成完整变体的语音隐私验证。

## 哪些内容可能保存在本地

- 内置词典、符号等资源，以及主动导入的离线模型。
- 主动添加或导入的个人词库与常用语。
- 明确启用候选学习后保存的候选词频。此开关默认关闭，另有临时不学习模式。
- 明确启用剪贴板历史后保存的剪贴板条目。此开关默认关闭，独立于词库与语音。
- 应用设置，以及设置故障恢复时保留的本地故障副本。

项目不把常规按键、密码或完整输入历史作为产品历史库，也不提供云同步或遥测功能。**不能因此说应用“从不保存用户文字”**：个人词条、常用语、剪贴板条目和自定义符号本身都可能含有文字。

## 备份与文件选择器

个人词库/常用语使用 JSON 备份，词库可从限定 TSV 导入。设置另用白名单 TSV 格式；它不包含剪贴板历史、录音、模型、学习记录，也不导出自动采集/学习的开启状态。部分较新开关不在设置白名单中，不能把它称为完整换机恢复。

备份可能包含自定义符号等手动输入的文字。文件中的 Base64 编码可逆，**不是加密**。如果你通过系统文件选择器选了云盘或其他提供方，文件会交给该提供方；“应用没有网络权限”不等于“导出的文件永不离开设备”。

Android 系统自动备份在当前清单中关闭。卸载或清理应用数据仍可能导致本地内容丢失；本项目不承诺跨构建、跨平台或跨设备自动恢复。

## 输入法权限与 beta 使用

输入法需要接触当前编辑框。密码字段保护依赖宿主提供的信息与实现行为，不能当成绝对隔离。宿主应用和系统也可能处理你输入的内容。

请勿使用调试签名 beta 输入密码、敏感信息或重要文本。反馈时使用合成文字，遮盖截图中的私人内容，不上传录音、个人词库、常用语或剪贴板备份。离线设计降低部分风险，并不消除软件缺陷、设备安全和第三方服务带来的风险。
